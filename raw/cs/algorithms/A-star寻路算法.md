# A* 寻路算法

## 概述

A*（A-star）是一种启发式搜索算法，广泛应用于游戏开发中的寻路系统。它结合了 Dijkstra 算法的最短路径保证和贪心最佳优先搜索的效率。

## 核心原理

A* 使用评估函数 `f(n) = g(n) + h(n)`：

- **g(n)**：从起点到节点 n 的实际代价
- **h(n)**：从节点 n 到终点的启发式估算代价（必须 ≤ 实际代价才能保证最优解）
- **f(n)**：通过节点 n 的预估总代价

## 常见启发式函数

### 曼哈顿距离（网格地图，4方向移动）
```
h = |x1 - x2| + |y1 - y2|
```

### 欧几里得距离（允许任意方向移动）
```
h = sqrt((x1 - x2)² + (y1 - y2)²)
```

### 对角线距离（网格地图，8方向移动）
```
h = max(|x1 - x2|, |y1 - y2|) + (√2 - 1) * min(|x1 - x2|, |y1 - y2|)
```

## 在 Unity 中的应用

Unity 的 NavMesh 系统内部使用 A* 变体进行寻路。在需要自定义网格寻路时，可以自己实现：

1. 创建导航网格（Grid/Graph）
2. 使用 PriorityQueue（最小堆）管理开放集
3. 维护 Closed Set 避免重复访问
4. 到达终点后回溯路径

## 优化技巧

- **跳点搜索（JPS）**：在均匀网格上大幅减少搜索节点数
- **分层寻路（HPA*）**：在大地图上先粗后细
- **路径平滑**：后处理消除不必要的拐点
- **多线程寻路**：将大批量寻路请求分发到 Job System
