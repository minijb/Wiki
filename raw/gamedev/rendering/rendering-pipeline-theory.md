# 渲染管线理论与图形学基础

> 基于 GAMES101、GAMES104、GAMES202 课程笔记，以及计算机图形学学习路线。

---

## 一、数学基础

### 1.1 线性代数

**向量（Vector）：**
- 表示：$\vec{a}$ 或 $\mathbf{a}$ 或 $\vec{AB} = B - A$
- 指向方向，无起始点
- 长度：$\left \| \vec{a} \right \|$
- 单位向量：$\hat{a} = \vec{a} / \left \| \vec{a} \right \|$
- 默认使用列向量，行向量记作 $A^T$

**点乘（Dot Product）：**
$$
\vec{a} \cdot \vec{b} = \left \| \vec{a}\right \| \left \| \vec{b}\right \| \cos{\theta}
$$

用途：
- 求夹角
- 找投影
- 确定方向前后关系（>0 同向，<0 反向）
- 分解向量

**叉乘（Cross Product）— 右手坐标系：**

$$
\vec{a} \times \vec{a} = 0
$$

用途：
- 判断左右关系（为正 → 在左，为负 → 在右）
- 判断点是否在三角形内部（三次叉乘符号一致）

**矩阵：**
- 乘法不满足交换律
- 转置：$(AB)^T = B^T A^T$
- 逆矩阵：$(AB)^{-1} = B^{-1} A^{-1}$
- $A^{-1}A = I$
- 坐标系变换：将向量从一组基变换到另一组基

### 1.2 齐次坐标

- 2D point = $(x, y, 1)^T$
- 2D vector = $(x, y, 0)^T$ — 平移不变性

向量 w=0 保证平移不影响向量，点 w=1 使平移生效。

## 二、变换（Transform）

### 2.1 二维变换

| 变换 | 矩阵形式 |
|:-----|:---------|
| 缩放 | `[Sx 0 0; 0 Sy 0; 0 0 1]` |
| 旋转 | `[cos -sin 0; sin cos 0; 0 0 1]` |
| 平移 | `[1 0 Tx; 0 1 Ty; 0 0 1]` |
| 仿射 | 先线性变换再平移 |

**逆变换** = 应用逆矩阵。

**变换组合 = 矩阵乘法**（从右到左应用）。

**变换分解**：变换到原点 → 旋转 → 变换回原始位置。

### 2.2 三维变换

与二维类似，使用 4×4 齐次矩阵。

**三维旋转：** 绕 X/Y/Z 轴的旋转矩阵。任意旋转可以通过欧拉角或四元数表示。

### 2.3 视图变换（View Transformation）

三步：Model Transform → View Transform → Projection Transform

**关键约定（MVP 变换）：**
- 相机永远在原点
- 看向 -Z 方向
- Y 轴为向上方向
- 如果相机和物体同时移动，效果相同

**$M_{view}$** 将相机移到原点（先求逆旋转再求逆平移）。

### 2.4 投影变换

**正交投影（Orthographic）：**
- 平行的线保持平行
- 步骤：将长方体移到原点 → 缩放到 $[-1,1]^3$ 标准立方体

**透视投影（Perspective）：**
- 平行的线不再平行（近大远小）
- 将截锥体（Frustum）挤压成长方体 → 再做正交投影
- 约束：近平面上任何点不变，远平面上任何点的 z 不变

**FOV（视场角）：** 分为水平和垂直。$\tan(\frac{fovY}{2}) = \frac{h/2}{near}$。

## 三、光栅化（Rasterization）

### 3.1 光栅化基础

光栅化 = 将几何图形绘制到屏幕上。

屏幕坐标系：像素索引从 (0,0) 到 (width-1, height-1)。像素 (x,y) 的中心在 (x+0.5, y+0.5)。

**采样法（Sampling）：** 判断像素中心是否在三角形内。

**判断 inside：** 三次叉乘（cross product），符号一致则在内部。

**加速方法：**
- **包围盒（Bounding Box）**：只检查三角形包围盒范围内的像素
- **增量遍历**：逐行扫描

### 3.2 反走样（Antialiasing）

**走样（Aliasing）**：采样伪影（Jaggies/锯齿）。

**产生原因：** 信号变化频率高于采样频率（采样定理）。

**反走样方法：** 在采样之前进行模糊（低通滤波），然后采样。

**频域视角：**
- 时域的乘积 = 频域的卷积
- 采样 = 重复原始信号的频谱
- 走样 = 频谱重叠（混叠）
- 反走样 = 先用低通滤波器截掉高频，再采样

**抗锯齿技术：**

| 技术 | 说明 |
|:-----|:-----|
| MSAA（Multi-Sample AA） | 每个像素多次采样取平均（增加计算量） |
| FXAA（Fast Approximate AA） | 后处理，快速近似 |
| TAA（Temporal AA） | 利用时间上多帧信息 |
| DLSS（Deep Learning Super Sampling） | 深度学习超采样 |

### 3.3 深度缓冲（Z-Buffer）

**画家算法**：从远到近绘制。缺点：无法处理相互遮挡。

**Z-Buffer 算法：**
- 存储每个像素当前最小深度值
- 光栅化时比较：当前深度 < 缓冲深度 → 更新颜色和深度
- 复杂度：O(n) for n triangles

**Z-Buffer 特点：**
- 与绘制顺序无关
- 不能处理透明物体（需单独处理）
- 浮点精度问题可能导致 Z-Fighting

## 四、着色（Shading）

### 4.1 着色定义

对不同物体应用不同材质。Shading ≠ Shadow。

### 4.2 漫反射（Diffuse Reflection）

光照角度影响亮度（Lambert's Cosine Law）：
$$
L_d = k_d \cdot (I / r^2) \cdot max(0, \mathbf{n} \cdot \mathbf{l})
$$
其中 $k_d$ 为漫反射系数，$I/r^2$ 为到达该点的光能。

### 4.3 高光项（Specular）

使用半程向量（Blinn-Phong）计算：
$$
\mathbf{h} = \frac{\mathbf{v} + \mathbf{l}}{\left\| \mathbf{v} + \mathbf{l} \right\|}
$$
$$
L_s = k_s \cdot (I / r^2) \cdot max(0, \mathbf{n} \cdot \mathbf{h})^p
$$

指数 $p$ 控制光斑大小（通常 200-600），半程向量比反射向量更容易计算。

### 4.4 环境光（Ambient）

$$
L_a = k_a \cdot I_a
$$

简化假设：所有点接收相同环境光，不依赖方向。

### 4.5 Blinn-Phong 反射模型

$$
L = L_a + L_d + L_s = k_a I_a + k_d (I/r^2) max(0, \mathbf{n} \cdot \mathbf{l}) + k_s (I/r^2) max(0, \mathbf{n} \cdot \mathbf{h})^p
$$

### 4.6 着色频率

| 频率 | 计算位置 | 效果 |
|:-----|:---------|:-----|
| Flat Shading | 每个三角形 | 面片效果 |
| Gouraud Shading | 每个顶点 | 平滑但可能有高光丢失 |
| Phong Shading | 每个像素 | 逐像素法线插值，最佳效果 |

**逐顶点法线计算：** 平均相邻面的法线（按面积加权）。
**逐像素法线计算：** 使用重心坐标在三角形内插值。

## 五、纹理映射（Texture Mapping）

### 5.1 基本概念

- 纹理是定义在 UV 坐标空间上的图像（通常 [0,1]²）
- 每个三角形顶点对应一个 UV 坐标
- 屏幕上三角形内部点的颜色通过 UV 坐标从纹理中查找

### 5.2 重心坐标（Barycentric Coordinates）

在三角形内做平滑插值。任意点 P：
$$
P = \alpha A + \beta B + \gamma C,\quad \alpha + \beta + \gamma = 1
$$

其中 $\alpha, \beta, \gamma$ 可通过面积比计算。**注意：投影后重心坐标会改变**，应在三维空间中计算。

### 5.3 纹理放大问题

**Texture Magnification**（纹理太小）：像素映射到的texel少于一个。

**解决方案：**
- **双线性插值（Bilinear）**：取周围4个texel线性插值
- **双三次插值（Bicubic）**：取周围16个texel三次插值

### 5.4 纹理过大问题与Mipmap

**问题**：近处一个像素对应多个texel → 走样（摩尔纹）。

**Mipmap**：预生成纹理的逐级降采样（多 1/3 存储）。允许快速、近似的方形范围查询。

**Mipmap Level 计算**：根据像素在纹理空间中覆盖的区域大小选择合适层级。

**三线性插值（Trilinear）**：在两层级间再做插值。资源消耗小，效果好。

**Mipmap的限制**：过度模糊（Overblur）。

**各向异性过滤（Anisotropic Filtering）**：解决 Mipmap 对非正方形区域的模糊问题（部分解决）。

**EWA过滤**：对任意形状区域进行加权平均。

### 5.5 纹理应用

| 用途 | 说明 |
|:-----|:-----|
| 环境光遮蔽（AO） | 预计算遮挡信息 |
| 凹凸贴图（Bump Map） | 扰动法线模拟几何细节 |
| 法线贴图（Normal Map） | 存储法线方向 |
| 位移贴图（Displacement Map） | 实际改变顶点位置 |
| 3D纹理/噪声 | Perlin Noise、程序化纹理 |
| 阴影贴图（Shadow Map） | 存储深度信息 |

## 六、几何（Geometry）

### 6.1 隐式几何 vs 显式几何

| | 隐式（Implicit） | 显式（Explicit） |
|:--|:--|:--|
| 表示 | $f(x,y,z) = 0$ | 参数化或点集 |
| 优点 | 容易判断内外 | 直观，容易枚举点 |
| 缺点 | 不直观，难以枚举 | 难判断内外 |

隐式方法：代数曲面、构造性立体几何（CSG）、距离函数（SDF）、水平集（Level Set）、分形（Fractal）。

显式方法：点云、多边形网格、细分曲面、NURBS、贝塞尔曲面。

### 6.2 贝塞尔曲线（Bezier Curves）

由控制点定义，通过多次线性插值（de Casteljau 算法）计算。

**性质：**
- 曲线必定经过起点和终点
- 起点切线方向 = 起点到第一个控制点方向
- 在仿射变换下：直接变换控制点即可
- 凸包性质：曲线位于控制点形成的凸包内

**分段贝塞尔曲线**：常用 4 个控制点控制一段。保证曲线光滑 → 连接点两侧的控制点共线且长度相同。

### 6.3 曲面细分（Subdivision）

**Loop 细分**（仅三角形网格）：
1. 将每个三角形一分四，增加三角形数量
2. 对新顶点和旧顶点分别调整位置（加权平均）

**Catmull-Clark 细分**（任意多边形网格）：
- 一次细分后所有非四边形面消失，奇异点增加
- 之后奇异点数量不再增加

### 6.4 网格简化（Mesh Simplification）

通过边坍缩（Edge Collapse）减少三角形数量。使用**二次误差度量**（Quadric Error Metrics）选择坍缩顺序。

## 七、光线追踪（Ray Tracing）

### 7.1 光线基础

**光线方程：** $P(t) = \mathbf{O} + t\mathbf{d}$，其中 $t \ge 0$。

**光线性质：**
- 直线传播
- 光线之间不会碰撞
- 光路可逆（从光源到人眼 = 从人眼到光源）

### 7.2 光线与物体求交

**与隐式表面：** 代入方程求解。

**与三角形求交：** 先和平面求交，再判断点是否在三角形内。或使用 **Möller-Trumbore 算法**一次性求解。

### 7.3 加速结构

**包围盒（Bounding Volume）：** 使用简单形状包住复杂物体。

**AABB（轴对齐包围盒）：** 面平行于坐标轴。光线与AABB求交 = 对每组平面求进入/离开时间，取交集。

**均匀空间划分（Grid）：**
- 将空间划分为均匀格子
- 光照与格子求交，沿光路依次检查格子内的物体
- 适合均匀分布的场景

**空间划分树：**
- **KD-Tree**：按轴对齐平面二分空间
- 问题：一个三角形可能与多个节点相交

**BVH（Bounding Volume Hierarchy）— 按物体划分：**
- 每次将物体集按某轴划分为两部分
- 每个节点存储其包含所有物体的包围盒
- 递归直到叶节点只有少量三角形
- 问题：包围盒可能重叠
- 划分策略：找中位数快速划分

### 7.4 Shadow Mapping（阴影映射）

**基本思想**：光源"看到"的点 + 相机看到的点 → 不在阴影中。

步骤：
1. 从光源位置渲染场景，生成深度图（Shadow Map）
2. 从相机位置渲染，对每个可见点计算其在光源空间的深度
3. 比较：当前深度 > Shadow Map 深度 → 在阴影中

**限制**：只能处理点光源（硬阴影）。

**问题**：浮点精度 → 阴影痤疮（Shadow Acne），表面自遮挡。

**硬阴影 vs 软阴影：**
- 硬阴影：点光源，边缘清晰
- 软阴影：面积光源，本影（Umbra）+ 半影（Penumbra）

## 八、辐射度量学与全局光照

### 8.1 辐射度量学术语

| 术语 | 符号 | 含义 |
|:-----|:-----|:-----|
| Radiant Energy | $Q$ | 辐射能量（J） |
| Radiant Flux (Power) | $\Phi$ | 单位时间能量（W） |
| Radiant Intensity | $I$ | 单位立体角功率（W/sr） |
| Irradiance | $E$ | 单位面积入射功率（W/m²） |
| Radiance | $L$ | 单位立体角单位面积功率（W/sr·m²） |

**立体角（Solid Angle）：** 三维空间中的"角度"，$\Omega = A / r^2$。

**Irradiance vs Radiance：**
- Irradiance：一个点接收到的**所有**方向的光线
- Radiance：一个点面向**某个方向**接收到的光线

### 8.2 BRDF（双向反射分布函数）

描述光线如何被表面反射：入射方向的光有多少被反射到出射方向。

$$
f_r(\omega_i \to \omega_r) = \frac{dL_r(\omega_r)}{dE_i(\omega_i)} = \frac{dL_r(\omega_r)}{L_i(\omega_i) \cos\theta_i \, d\omega_i}
$$

### 8.3 反射方程

$$
L_r(p, \omega_r) = \int_{H^2} f_r(p, \omega_i \to \omega_r) L_i(p, \omega_i) \cos\theta_i \, d\omega_i
$$

### 8.4 渲染方程（The Rendering Equation）

$$
L_o(p, \omega_o) = L_e(p, \omega_o) + \int_{H^2} f_r(p, \omega_i \to \omega_o) L_i(p, \omega_i) \cos\theta_i \, d\omega_i
$$

其中 $L_e$ 为自发光项。

### 8.5 蒙特卡洛积分（Monte Carlo Integration）

用随机采样近似积分：

$$
\int f(x) dx \approx \frac{1}{N} \sum_{i=1}^N \frac{f(X_i)}{p(X_i)}
$$

### 8.6 路径追踪（Path Tracing）

Whitted-style 光线追踪的问题：只处理完美镜面反射/折射，对漫反射表面不真实。

**路径追踪算法：**
1. 对每个像素多次发射光线
2. 每次击中表面后，随机采样一个方向继续追踪
3. 使用蒙特卡洛积分估计渲染方程
4. **俄罗斯轮盘赌（Russian Roulette）**：以概率 p 继续追踪，结果除以 p 保持无偏

**直接光照 + 间接光照分离：**
- 对光源直接采样（重要性采样），避免浪费光线
- 间接光照随机采样半球

### 8.7 高级光线传播方法

| 方法 | 类型 | 说明 |
|:-----|:-----|:-----|
| 路径追踪（Path Tracing） | 无偏 | 基础方法 |
| 双向路径追踪（BDPT） | 无偏 | 从相机和光源同时追踪 |
| Metropolis Light Transport（MLT） | 无偏 | 马尔科夫链采样，适合复杂光照 |
| 光子映射（Photon Mapping） | 有偏 | 两阶段法，擅长焦散 |

## 九、材质与外观

### 9.1 菲涅尔项（Fresnel）

反射率随入射角变化：掠射角（接近平行）时反射率接近 1。

- **绝缘体**：垂直入射时反射率低
- **导体**：所有角度都有较高反射率

Schlick 近似：$R(\theta) = R_0 + (1 - R_0)(1 - \cos\theta)^5$

### 9.2 微表面模型（Microfacet）

表面由微小镜面组成。粗糙度由微表面法线分布描述：
- 法线集中 → 镜面（Glossy）
- 法线发散 → 漫反射（Diffuse）

**当前业界标准模型**，可描述大量真实材质。

### 9.3 各向同性/各向异性 BRDF

- **各向同性（Isotropic）**：旋转表面不改变反射
- **各向异性（Anisotropic）**：不同方向有不同反射（如拉丝金属的条形高光）

### 9.4 参与介质（Participating Media）

光线在介质中传播时发生散射和吸收（如雾、云、烟）。

### 9.5 次表面散射（Subsurface Scattering, SSS）

光线进入半透明物体后在内部散射并从别处出射（如皮肤、玉石、牛奶）。

**BSSRDF** 泛化了 BRDF，允许出射点与入射点不同。

## 十、相机与光场

### 10.1 曝光三要素

- **光圈（Aperture）**：F数 = 焦距/直径，F数越小光圈越大
- **快门速度（Shutter Speed）**：曝光时间
- **ISO（感光度）**：信号放大倍率（但会放大噪声）

### 10.2 薄透镜近似

**透镜公式**：$\frac{1}{f} = \frac{1}{z_i} + \frac{1}{z_o}$

$z_i$ — 像距，$z_o$ — 物距，$f$ — 焦距。

### 10.3 景深（Depth of Field）

**Circle of Confusion（CoC）**：不在焦点上的点形成的模糊圆。CoC 大小决定模糊程度。

### 10.4 光场（Light Field）

全光函数（Plenoptic Function）：描述空间每个点、每个方向、每个波长的光。

使用两个平面参数化光线（4D光场 $L(u,v,s,t)$）。

**光场相机**：在传感器前放置微透镜阵列，记录光线的方向信息 → 支持拍摄后重聚焦。

## 十一、颜色科学

### 11.1 颜色感知

人眼有三种锥形细胞（S/M/L，对应短/中/长波长）。**同色异谱（Metamerism）**：不同光谱可以产生相同颜色感知。

### 11.2 颜色空间

- **sRGB**：标准 RGB，广泛用于显示器
- **CIE XYZ**：标准观察者颜色匹配函数
- **色域（Gamut）**：一个设备能表示的颜色范围

## 十二、动画与物理模拟

### 12.1 关键帧动画

在关键帧之间插值。**Blend Space**：使用插值生成不同状态间过渡动画。

### 12.2 质点弹簧系统（Mass-Spring System）

- 弹簧力：$f_{a\to b} = k_s \frac{b-a}{\|b-a\|}(\|b-a\| - l)$
- 阻尼力：与相对速度有关，投影到弹簧方向上
- 结构：剪切弹簧、弯曲弹簧等不同强度

**正向运动学（Forward Kinematics）**：给定关节角度求末端位置。
**逆运动学（Inverse Kinematics, IK）**：给定末端位置求关节角度（解不唯一，可能无解）。

### 12.3 数值积分方法

| 方法 | 特点 |
|:-----|:-----|
| 欧拉方法（Euler） | 简单但误差大、不稳定 |
| 中点法（Midpoint） | 用中点导数，二阶精度 |
| 自适应步长 | 误差大时减半步长 |
| 隐式欧拉 | 用下一步导数，更稳定但难解 |
| Runge-Kutta 4阶 | 经典高阶方法 |
| Verlet / Position-Based | 常用在游戏物理中 |

### 12.4 粒子系统（Particle System）

大量粒子受各种力作用的模拟。需要加速结构（如空间哈希）。

### 12.5 刚体模拟

在质点基础上增加旋转自由度和碰撞响应。流体可用粒子（如 SPH 方法）近似模拟。

## 十四、图形学面试要点

### 14.1 渲染管线阶段

**经典管线顺序：**
Vertex Shader → Tessellation → Geometry Shader → Clipping → Primitive Assembly（面剔除）→ Rasterization → Fragment Shader

### 14.2 顶点着色器 vs 像素着色器

**顶点着色器：**
- 输入：顶点数据（位置、法线、纹理坐标）、常量（变换矩阵）
- 输出：变换后的顶点属性（裁剪空间位置、颜色、UV等，传给光栅化阶段插值）

**像素（片元）着色器：**
- 输入：光栅化阶段生成的插值后片元信息（颜色、UV、深度、法线）
- 输出：每个像素的最终颜色值（还可输出深度值等）

### 14.3 碰撞检测方法

| 方法 | 说明 |
|:-----|:-----|
| AABB | 轴对齐包围盒，最简单快速 |
| OBB | 有向包围盒，随物体旋转，更精确 |
| Sphere | 球形包围盒，适用于球状物体 |
| 分离轴定理（SAT） | 检测凸多边形之间是否有间隙 |
| DCD（离散碰撞检测） | 逐帧查询瞬时相交 |
| CCD（连续碰撞检测） | 考虑帧间运动轨迹，防止穿透 |

**分离轴定理（SAT）原理**：从多个方向投影两个图形，如果所有投影轴上都重叠则碰撞；找到任何一个间隙则未碰撞。只适用于凸多边形。

### 14.4 Mipmap 要点

- 图像远离时采样率与分辨率不匹配 → 锯齿
- Mipmap 预生成不同尺寸的纹理，根据距离选择合适尺寸
- 增大包体约 1.33 倍
- 减少传输带宽，消除像素闪烁
