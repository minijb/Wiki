# 操作系统基础

## 来源信息

- **原始文件**：`raw/cs/architecture/os-fundamentals.md`
- **类型**：技术参考文档

## 要点

- **状态机模型**：程序即状态机（内存/寄存器+状态迁移），OS 提供进程/虚拟内存/文件三大抽象，应用程序 = 计算 + 系统调用；编译器优化三板斧（内联/常量传播/死代码消除）
- **进程管理**：创建→就绪→运行→阻塞/终止的状态转换；fork 复制地址空间（COW），execve 替换程序映像；上下文切换保存/恢复寄存器+页表+内核栈
- **进程 vs 线程切换**：线程切换无需切换页表，TLB 不失效，速度远快于进程切换
- **线程与协程**：线程为抢占式（OS 调度），协程为非抢占式（用户管理）；一个线程可有多个协程，协程保留调用状态
- **调度算法**：FCFS/SJF/STCF/RR/优先级调度；MLFQ 五条规则（优先级分层、时间片消耗降级、定期提升防饥饿）
- **同步机制**：临界区（仅限本进程）→ 互斥量（跨进程）→ 信号量（计数器，count=1 即互斥量）→ 事件（通知机制）
- **死锁四要素**：互斥、请求保持、不剥夺、循环等待；破除策略（一次性申请/允许抢占/按序申请）
- **IPC 方式**：管道（半双工/父子进程）、信号（异步通知）、信号量（PV 操作）、消息队列、共享内存（最快但需同步）、Socket（最通用）
- **虚拟内存**：页表实现 VA→PA 映射，缺页异常触发磁盘加载；TLB 缓存页表项，进程切换需刷新 TLB（慢的主要原因）
- **分页 vs 分段**：分页一维定长（内部碎片），分段二维可变（外部碎片+逻辑保护）
- **页替换算法**：FIFO→第二次机会→时钟算法→LRU（最优但硬件难）→老化算法（近似 LRU）→工作集算法
- **交换空间**：物理内存不足时页面换出到磁盘；物理内存 + 交换 = 虚拟内存总量
- **I/O 多路复用**：select/poll（O(n) 轮询）→ epoll（O(1) 事件驱动），epoll 通过内核事件表 + 回调通知实现高效并发
- **硬链接 vs 软链接**：硬链接同 inode（不能跨文件系统/不能指向目录），软链接存路径（可跨文件系统，原文件删除则断链）
- **/proc 文件系统**：内核虚拟文件系统，暴露 CPU/内存/进程信息（cpuinfo/meminfo/[pid]/status/cmdline/fd）
- **中断处理**：保护现场→开中断→ISR→关中断→恢复现场的五步流程
- **地址术语**：逻辑地址（段内偏移）→线性地址（段基址+偏移）→物理地址（页表转换后）
