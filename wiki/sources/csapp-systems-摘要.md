# CSAPP 系统级主题

## 来源信息

- **原始文件**：`raw/cs/architecture/csapp-systems.md`
- **类型**：技术参考文档

## 要点

- **处理器微架构**：Y86-64 精简指令集（15 寄存器、8 种指令、3 条件码），顺序五阶段流水（Fetch→Decode→Execute→Memory→Write Back→PC Update），各阶段的硬件实现细节和数据通路
- **流水线设计**：通过分阶段重叠执行提高吞吐量，时钟周期由最慢阶段决定；面临的冒险：数据冒险（前一条结果供后一条使用）、控制冒险（分支导致预取失效）
- **程序优化策略**：消除函数调用开销（循环不变量外提）、消除不必要的内存引用（寄存器代替内存累加）、循环展开（减少分支）+ 多累加器（打破关键路径依赖）、利用指令级并行
- **编译器优化障碍**：内存别名使编译器不敢激进优化（两个指针可能指向同一地址）；函数副作用使调用不可消除
- **分支预测**：CPU 推测执行分支，预测正确零开销，预测失败丢约 15-20 周期；性能计数器（latency/issue time/capacity）反映微架构特性
- **存储技术栈**：SRAM(L1/L2/L3)→DRAM(主存)→NAND Flash(SSD)→磁性介质(HDD)，各级的访问延迟和持久性差异
- **缓存组织**：直接映射 / N-路组相联 / 全相联三种映射方式；地址按 Tag/Set/Offset 划分；缓存访问三步走（组选择→行匹配→字抽取）
- **写策略**：写穿透 vs 写回（dirty bit），写分配 vs 写不分配，现代 CPU 主流为写回+写分配
- **缓存性能**：冲突 miss（直接映射的抖动）、容量 miss、冷 miss；替换算法（LRU/FIFO/随机/伪 LRU）
- **ELF 文件结构**：.text/.rodata/.data/.bss/.symtab 等节的存放内容；符号表（全局/外部/局部符号，强符号与弱符号规则）
- **静态链接**：链接器维护 E/U/D 三集合，从左到右扫描处理 `.o` 和 `.a`；静态库的符号解析按需提取；链接顺序敏感
- **重定位**：合并同类节 + 填充符号地址；PC 相对寻址（计算偏移量）与绝对寻址两种方式
- **异常控制流**：中断（外部 I/O）、陷阱（syscall）、故障（缺页等可恢复错误）、中止（硬件错误）四类异常
- **进程管理**：fork 创建子进程（写时复制）、execve 替换进程映像；父进程 wait/waitpid 回收僵尸；上下文切换与进程状态转换
- **信号机制**：信号产生→内核设 pending 位→返回用户态时检查处理；隐式/显式信号阻塞；信号安全编码准则（volatile sig_atomic_t、保存 errno）
- **虚拟内存**：页/页框/页表，MMU 地址翻译（VA→PA），TLB 缓存页表项加速翻译；多级页表节省空间
- **内存映射**：惰性加载（缺页时才真正从磁盘读取）；文件映射 vs 匿名映射；共享映射 vs 私有写时复制（fork 的实现基础）
- **动态内存分配**：brk/sbrk 系统调用，malloc/free/calloc/realloc 库函数；内部碎片（对齐浪费）vs 外部碎片（空闲块分散）；隐式/显式/分离空闲链表管理
