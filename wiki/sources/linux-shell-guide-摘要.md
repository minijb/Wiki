# Linux Shell 环境完全指南

## 来源

`raw/tools/shell/linux-shell-guide.md` — Linux Shell 环境完整指南：Bash 脚本编程、Fish/Zsh Shell 配置、终端多路复用、Neovim 环境、高效 CLI 工具、包管理、代理配置、文件系统基础

## 要点

1. **Bash 脚本编程** — 变量/数组/字符串操作（子串/替换/匹配）、条件判断（数字/字符串/文件测试）、循环（for/while/until/C风格）、函数、trap 信号捕获、重定向与 Heredoc
2. **Fish Shell** — 自然语法（无 `then`/`fi`/`do`/`done`）、命令替代用 `()`、function 替代 alias、`~/.config/fish/` 自动加载、Web 配置界面（`fish_config`）、历史搜索/建议采纳
3. **Zsh + Oh My Zsh** — 安装、Antigen 插件管理器、常用插件（git/docker/extract/zsh-autosuggestions）
4. **终端多路复用** — tmux 会话/窗格管理（`Prefix`=`Ctrl+b`）
5. **Neovim 生态** — PPA 安装、LazyVim、竞赛/笔记/大纲插件推荐
6. **高效工具** — lazygit（终端 Git GUI）、fzf（模糊搜索）、ripgrep（rg，极速文本搜索）、fd（文件查找）
7. **文件系统** — `chmod`/`chown`/`chgrp` 权限管理、目录结构（`/usr`/`/etc`/`/var`）
