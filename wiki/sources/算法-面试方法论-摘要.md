# 算法面试通用方法论

## 来源

`raw/cs/algorithms/interview-patterns.md` — 图论、A* 寻路、红黑树、链表/双指针/滑动窗口/哈希/栈等经典模式、游戏数学几何、面试策略

## 要点

1. **图论算法** — Prim（`minDist` + `isInTree`，选离生成树最近节点）、Kruskal（并查集 + 边排序，避免成环）、拓扑排序（入度为 0 的节点反复移除，DAG 线性排序，有剩余节点 → 有环）
2. **并查集 (DSU)** — 路径压缩 `father[u] = find(father[u])` 均摊接近 $O(1)$；支持连通性判断与环检测
3. **A\* 寻路** — $F = G + H$，四种优化：优先队列实现 OpenList、JPS 跳点搜索、启发函数引入拐弯惩罚/HPA 分层优化
4. **红黑树** — 根和叶子必黑、红节点不连续、所有路径黑节点数相同；插入 4 种情况（父黑直接插/父红叔红换色/父红叔黑旋转）、删除 5 种情况（单红直接删/单子红替换黑/双子找前驱替换 + 兄弟黑 4 子情况/兄弟红旋转转换）
5. **链表经典** — 反转链表（双指针迭代）、删除倒数第 N 个（快慢指针 + dummy）、两两交换
6. **双指针/滑动窗口** — 盛最多雨水（左右指针向中间收缩）、无重复字符最长子串（哈希记录最后位置）、长度最小子数组（扩张 + 收缩）
7. **数组变换** — 轮转数组（取模映射）、旋转矩阵（转置 + 左右翻转）、颜色分类/荷兰国旗（三指针一次遍历）
8. **哈希妙用** — 两数之和（互补查找）、构造最长回文串（字符计数）、只出现一次的数字（异或）
9. **栈** — 有效括号（匹配弹出）、比较版本号（逐段解析，防溢出用 `long long`）
10. **游戏数学几何** — 左右判断（叉积 y 分量符号）、点是否在三角形内（三边叉积同号）、2D 旋转公式、面向/背向（点乘符号）、反射向量 $R = I - 2(I\cdot N)N$、矩形相交判定及相交区域计算、圆环随机三点锐角三角形概率 $1/4$
11. **面试策略** — 先确认边界 → 口述思路 → 编码 → 跑测试 → 分析复杂度 → 讨论优化；题型优先级：数组/字符串 > 双指针/滑动窗口 > 二叉树/BST > DP > 回溯 > 栈/队列 > 图论 > 高级数据结构
