# A* 算法

启发式搜索算法，用于在图中找到两点之间的最短路径。

## 定义

A* 使用评估函数选择下一个要探索的节点：

$$f(n) = g(n) + h(n)$$

- **g(n)**：从起点到节点 n 的**实际代价**
- **h(n)**：从节点 n 到终点的**启发式估算**（必须 ≤ 实际代价，即 admissible）
- **f(n)**：通过节点 n 的预估总代价，每次选择 f 最小的节点扩展

## 算法步骤

1. 将起点加入 Open Set（优先队列，按 f 值排序）
2. 从 Open Set 取出 f 最小的节点
3. 若该节点为终点 → 回溯路径，完成
4. 将该节点加入 Closed Set
5. 扩展邻居节点，更新 g/f 值
6. 重复 2-5
