# 光线追踪入门

基于 *Ray Tracing in One Weekend* 的实践笔记，从零实现光线追踪器。

## 核心数据结构

```cpp
class vec3 { double e[3]; };     // 向量/颜色/点
class ray { point3 orig; vec3 dir; };  // 光线
class hittable { virtual bool hit(...) }; // 可击中对象
class material { virtual bool scatter(...) }; // 材质
```

## 光线求交

### 光线-球体
从 $P(t) = A + td$ 和 $(C-P) \cdot (C-P) = r^2$ 推导二次方程：
$$t = \frac{h \pm \sqrt{h^2 - ac}}{a}$$
其中 $h = d \cdot (C-A)$，$a = d \cdot d$，$c = (C-A) \cdot (C-A) - r^2$。

### 加速
场景遍历使用 `hittable_list` 线性扫描。大规模场景需要 BVH 等空间加速结构。

## 反走样

每像素多重采样（`samples_per_pixel`），采样点在像素内随机偏移：
```cpp
auto offset = sample_square();  // [-0.5, 0.5]²
auto pixel_sample = pixel00_loc + ((i+offset.x())*delta_u) + ((j+offset.y())*delta_v);
```

## 材质类型

### Lambertian（漫反射）
`scatter_direction = normal + random_unit_vector()`

### Metal（金属）
- 镜面反射：$\mathbf{r} = \mathbf{v} - 2(\mathbf{v} \cdot \mathbf{n})\mathbf{n}$
- 模糊度 `fuzz`：`reflected = unit_vector(reflected) + fuzz * random_unit_vector()`
- 散射线在表面下方则吸收

### Dielectric（玻璃）
- **折射**：Snell 定律 $\eta \cdot \sin\theta = \eta' \cdot \sin\theta'$
- **全内反射**：$\frac{\eta}{\eta'} \sin\theta > 1$ 时无折射，全反射
- **Schlick 近似**：$R(\theta) = R_0 + (1-R_0)(1-\cos\theta)^5$

### 渲染循环
```cpp
color ray_color(ray r, int depth, hittable world) {
    if (depth <= 0) return black;
    if (world.hit(r, interval(0.001, inf), rec)) {
        ray scattered; color attenuation;
        if (rec.mat->scatter(r, rec, attenuation, scattered))
            return attenuation * ray_color(scattered, depth-1, world);
        return black;
    }
    return background_gradient(r); // 天空色
}
```

## 相机

### FOV
$\tan(vfov/2) = viewport\_height / (2 \cdot focal\_length)$

### 定向
lookfrom/lookat/vup → 正交基 (u, v, w)：
- w = lookfrom - lookat（-Z方向）
- u = cross(vup, w)（右方向）
- v = cross(w, u)（上方向）

### 景深
模拟镜头光圈：光线起点在圆盘上随机偏移 → 所有光线聚焦于焦平面。
