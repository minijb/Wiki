# 光线追踪入门

基于 *Ray Tracing in One Weekend* 的实践笔记，从零用 C++ 实现一个完整的路径追踪器（Path Tracer）。

## 核心数据结构

```cpp
class vec3 { double e[3]; };     // 向量/颜色/点（通过类型别名区分语义）
class ray { point3 orig; vec3 dir; };  // 光线 P(t)=A+tb
class hit_record { point3 p; vec3 normal; shared_ptr<material> mat; double t; bool front_face; };
class hittable { virtual bool hit(ray, interval, hit_record&) }; // 可击中对象
class material { virtual bool scatter(ray, hit_record, color& attenuation, ray& scattered) }; // 材质
```

## 光线求交

### 光线-球体
从 $P(t) = A + td$ 和 $(C-P) \cdot (C-P) = r^2$ 推导二次方程：
$$t = \frac{h \pm \sqrt{h^2 - ac}}{a}$$
其中 $h = d \cdot (C-A)$（简化形式，比标准二次方程少除一次 2），$a = d \cdot d$，$c = (C-A) \cdot (C-A) - r^2$。

取较小正根为最近交点。法线 = $(P-C)/r$。

### Hittable 抽象与场景管理
`hittable_list` 线性扫描场景中所有物体，每次找到更近交点就收缩搜索范围（`closest_so_far = temp_rec.t`）。

`set_face_normal`：`front_face = (ray_dir · outward_normal < 0)`。法线始终指向光线来向。对玻璃等内外两面物体至关重要。

### Interval 类
管理光线参数的合法范围：`interval(t_min, t_max)`。预设 `empty(+∞,-∞)` 和 `universe(-∞,+∞)`。

## 反走样

每像素多重采样（`samples_per_pixel`），采样点在像素内随机偏移 `[-0.5, 0.5]^2`：
```cpp
auto offset = sample_square();  // [-0.5, 0.5]²
auto pixel_sample = pixel00_loc + ((i+offset.x())*delta_u) + ((j+offset.y())*delta_v);
```

Gamma 校正：`linear_to_gamma(x) = sqrt(x)`（γ=2），使暗部获得更多精度，亮度过渡平滑。最终颜色钳制到 [0, 0.999]。

## 材质类型

### Lambertian（漫反射）
- 均匀半球：`scatter_direction = random_on_hemisphere(normal)`，每次吸收 50%
- **True Lambertian**（更真实）：`scatter_direction = normal + random_unit_vector()`，分布正比于 $\cos\theta$（更多光线沿法线方向散射）
- 防止零向量散射线（与法线完全反向时退化）

### Metal（金属）
- 镜面反射：$\mathbf{r} = \mathbf{v} - 2(\mathbf{v} \cdot \mathbf{n})\mathbf{n}$
- 模糊度 `fuzz`：`reflected = unit_vector(reflected) + fuzz * random_unit_vector()`，模糊球越大越漫反射
- 散射线在表面下方则吸收（`dot(scattered_dir, normal) <= 0`）

### Dielectric（玻璃/电介质）
- **折射**：Snell 定律 $\eta \cdot \sin\theta = \eta' \cdot \sin\theta'$
- **全内反射**：$\frac{\eta}{\eta'} \sin\theta > 1$ 时无折射，全反射（水下看水面像镜子）
- **折射率比**：`front_face ? (1.0/ri) : ri`（空气↔介质转换）
- **Schlick 近似**（菲涅尔效应）：$R(\theta) = R_0 + (1-R_0)(1-\cos\theta)^5$，掠射角反射率更高
- Attenuation 始终为 1（玻璃表面不吸收光）

### 空心玻璃球
外球折射率 1.50 + 内球折射率 1.00/1.50 = 0.67。光线路径：外球折射→内球折射→空气→内球内表面折射→外球内表面折射→场景。

### 渲染循环（递归路径追踪）
```cpp
color ray_color(ray r, int depth, hittable world) {
    if (depth <= 0) return black;  // 俄罗斯轮盘赌简化
    if (world.hit(r, interval(0.001, inf), rec)) {
        ray scattered; color attenuation;
        if (rec.mat->scatter(r, rec, attenuation, scattered))
            return attenuation * ray_color(scattered, depth-1, world);
        return black;
    }
    return background_gradient(r); // 天空色（Y 方向渐变）
}
```

Shadow Acne 修复：`t_min = 0.001` 忽略极近交点（浮点精度误差导致自相交）。

## 相机

### FOV
$\tan(vfov/2) = viewport\_height / (2 \cdot focus\_dist)$

### 定向
lookfrom/lookat/vup → 正交基 (u, v, w)：
- w = `unit_vector(lookfrom - lookat)`（-Z 方向）
- u = `unit_vector(cross(vup, w))`（右方向）
- v = `cross(w, u)`（上方向）

vup 只要不平行于视线即可，典型值 `(0, 1, 0)`。

### 景深（Defocus Blur）
模拟真实相机光圈（薄透镜近似）：光线起点在镜头圆盘上随机偏移（`defocus_angle` 控制模糊程度），所有光线聚焦于焦平面（距离 `focus_dist`）上的物体完美聚焦，越远越模糊。

```cpp
auto defocus_radius = focus_dist * tan(degrees_to_radians(defocus_angle / 2));
// 从圆盘随机点发射光线，ray_direction 指向焦平面上的像素采样点
```

defocus_angle = 0 退化为针孔相机（无模糊）。

## 完整场景

最终场景包含：地面大球 + 随机小球矩阵（随机材质：漫反射/金属/玻璃） + 三个展示球（玻璃/漫反射/金属）+ 可定位相机 + 景深。典型参数：1200px 宽，500 spp，50 深度。
