# CSAPP 程序结构与机器级表示

## 概念

涵盖 CSAPP 第 1-4 章内容：从 C 源码的编译过程到 x86-64 机器级编程。理解程序如何从高级语言编译为二进制、硬件如何执行指令、数据如何在位级别表示。

核心线索：**源码 → 编译 → 机器指令 → 硬件执行**，逐层深入从抽象到具体。

## 技术要点

### 编译流水线

预处理 (`.c` → `.i`) → 编译 (`.i` → `.s`) → 汇编 (`.s` → `.o`) → 链接 (`.o` → executable)。每个阶段有专门的工具和中间产物，链接阶段完成符号解析与重定位。

### 二进制数据表示

- **补码**整数：TMin 的特殊性（`-TMin = TMin`）
- **大端 vs 小端**：网络字节序 vs x86 主机序
- **符号扩展**：有符号数用符号位填充，无符号数用零填充
- **有符号/无符号混用**：运算时自动提升为无符号 ← 常见 bug 来源

### x86-64 汇编

- 16 个 64 位通用寄存器，各有用途约定（返回值/参数/栈指针/调用者保存/被调用者保存）
- 灵活的寻址模式：`D(Rb, Ri, S)` = `Mem[Rb + Ri×S + D]`
- 条件码 (CF/ZF/SF/OF) → `setX`/`jX`/`cmov` 三种控制流实现方式
- 有符号比较使用 `SF ^ OF` 而非仅 SF

### 栈帧与调用约定

```
高地址 参数 7+  | 返回地址 | 保存的寄存器 | 局部变量  低地址 (rsp)
```

`call` 压入返回地址，`ret` 弹出后跳转。前 6 个参数经寄存器传递。调用者负责保存易失寄存器，被调用者负责保存需持久化的寄存器。
