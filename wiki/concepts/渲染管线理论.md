# 渲染管线理论

基于 GAMES101/GAMES104/GAMES202 课程的计算机图形学核心理论。

## 渲染管线

```
顶点处理 → 曲面细分 → 几何着色器 → 裁剪 → 图元装配 → 光栅化 → 片元处理 → 帧缓冲
```

### MVP 变换

1. **Model**：局部空间 → 世界空间
2. **View**：世界空间 → 相机空间（相机在原点，看向 -Z）
3. **Projection**：相机空间 → 裁剪空间（正交/透视）

## Blinn-Phong 反射模型

$$
L = k_a I_a + k_d (I/r^2) max(0, \mathbf{n} \cdot \mathbf{l}) + k_s (I/r^2) max(0, \mathbf{n} \cdot \mathbf{h})^p
$$

- $L_a$：环境光（常数近似）
- $L_d$：漫反射（Lambert 余弦定律）
- $L_s$：高光（半程向量 $\mathbf{h}$，指数 $p$ 控制光斑大小）

## 纹理映射

- **双线性插值**：放大时平滑过渡
- **Mipmap**：多级纹理，三线性插值，$\sim$1.33× 存储
- **各向异性过滤**：解决非正方形区域模糊

## 反走样

- **MSAA**：每像素多次采样 → 硬件支持但计算量大
- **FXAA**：后处理快速近似
- **TAA**：时间域累积多帧信息
- **DLSS**：深度学习超采样

## 光线追踪

### 光线方程
$P(t) = \mathbf{O} + t\mathbf{d}$（$t \ge 0$）

### 加速结构
**BVH**（Bounding Volume Hierarchy）：按物体划分，最常用。递归二分物体集，每节点存包围盒。

### Shadow Mapping
1. 光源视角渲染深度图
2. 正常渲染时比较深度 → 判断阴影

### 辐射度量学

| 量 | 含义 |
|:---|:-----|
| Radiant Flux $\Phi$ | 单位时间能量（W） |
| Radiant Intensity $I$ | 单位立体角功率（W/sr） |
| Irradiance $E$ | 单位面积入射功率（W/m²） |
| Radiance $L$ | 单位立体角单位面积功率（W/sr·m²） |

### BRDF 与渲染方程

$$
L_o(p, \omega_o) = L_e(p, \omega_o) + \int_{H^2} f_r(p, \omega_i \to \omega_o) L_i(p, \omega_i) \cos\theta_i \, d\omega_i
$$

### 路径追踪
蒙特卡洛积分 + 俄罗斯轮盘赌（无偏） + 直接光照重要性采样。

## 几何处理

- **贝塞尔曲线**：de Casteljau 算法，凸包性质
- **Loop 细分**：三角形一分四，加权更新顶点
- **Catmull-Clark**：任意多边形 → 四边形，一次细分后奇异点不再增加
- **网格简化**：边坍缩 + 二次误差度量

## 材质模型

- **菲涅尔**：$R(\theta) = R_0 + (1-R_0)(1-\cos\theta)^5$（Schlick 近似）
- **微表面**：粗糙度 = 微表面法线分布 [扩散 ↔ 集中]
- **各向异性**：拉丝金属的条形高光
- **次表面散射**：BSSRDF 泛化 BRDF

## 动画物理

- **质点弹簧**：结构/剪切/弯曲弹簧
- **IK**：给定末端求关节角（解不唯一，可能无解）
- **数值积分**：欧拉 → 中点法 → RK4 → Verlet / Position-Based

## 引擎架构

GAMES104 五层：Tool → Function → Resource → Core → Platform
