# 渲染管线理论

基于 GAMES101/GAMES104/GAMES202 课程的计算机图形学核心理论，覆盖从数学基础到全局光照的完整知识体系。

## 数学基础

- **齐次坐标**：点 w=1（平移生效），向量 w=0（平移不变）
- **点乘**：求夹角、投影、判断前后（>0 同向，<0 反向）
- **叉乘**：判断左右（右手坐标系）、判断点是否在三角形内（三次叉乘符号一致）
- **矩阵**：组合从右到左，$(AB)^T = B^T A^T$，$(AB)^{-1} = B^{-1} A^{-1}$

## 渲染管线

```
顶点处理 → 曲面细分 → 几何着色器 → 裁剪 → 图元装配 → 光栅化 → 片元处理 → 帧缓冲
```

### MVP 变换

1. **Model**：局部空间 → 世界空间
2. **View**：世界空间 → 相机空间（相机在原点，看向 -Z）。若相机和物体同时移动，效果相同
3. **Projection**：相机空间 → 裁剪空间。正交（平行线保持平行）：长方体→$[-1,1]^3$；透视（近大远小）：Frustum→长方体→正交

FOV 关系：$\tan(fovY/2) = (h/2)/near$

## Z-Buffer

每像素存最小深度值。O(n) 复杂度，与绘制顺序无关。不能处理透明物体。浮点精度导致 Z-Fighting。

## Blinn-Phong 反射模型

$$
L = k_a I_a + k_d (I/r^2) max(0, \mathbf{n} \cdot \mathbf{l}) + k_s (I/r^2) max(0, \mathbf{n} \cdot \mathbf{h})^p
$$

- $L_a$：环境光（常数近似）
- $L_d$：漫反射（Lambert 余弦定律）
- $L_s$：高光（半程向量 $\mathbf{h} = (\mathbf{v}+\mathbf{l})/|\mathbf{v}+\mathbf{l}|$，指数 $p$ ≈ 200-600 控制光斑大小）

着色频率：Flat（面）→ Gouraud（顶点插值）→ Phong（逐像素法线插值）。

## 纹理映射

- **双线性插值**：放大时周围 4 texel 线性插值。双三次：16 texel
- **Mipmap**：多级纹理逐级降采样（约 1.33× 额外存储）。三线性插值：两层 Mipmap 间再插值
- **各向异性过滤**：解决非正方形区域模糊
- **EWA 过滤**：任意形状区域加权平均
- 应用：环境光遮蔽（AO）、凹凸贴图、法线贴图、位移贴图、3D 纹理/噪声、阴影贴图

## 反走样

- **MSAA**：每像素多次采样 → 硬件支持但计算量大
- **FXAA**：后处理快速近似
- **TAA**：时间域累积多帧信息（可能有重影）
- **DLSS**：深度学习超采样（NVIDIA RTX）
- **SMAA**：形态学抗锯齿

## 光线追踪

### 光线方程
$P(t) = \mathbf{O} + t\mathbf{d}$（$t \ge 0$）。光线性质：直线传播、光线间不碰撞、光路可逆。

### 加速结构
**BVH**（Bounding Volume Hierarchy）：按物体划分，最常用。递归二分物体集，每节点存包围盒。对比：KD-Tree（空间划分，三角形可能跨节点）。

### Shadow Mapping
1. 光源视角渲染深度图
2. 正常渲染时比较深度 → 当前深度 > Shadow Map 深度 → 在阴影中
3. 限制：只能处理点光源（硬阴影）、Shadow Acne（浮点精度自遮挡）

### 辐射度量学

| 量 | 含义 | 单位 |
|:---|:-----|:-----|
| Radiant Flux $\Phi$ | 单位时间能量 | W |
| Radiant Intensity $I$ | 单位立体角功率 | W/sr |
| Irradiance $E$ | 单位面积入射功率 | W/m² |
| Radiance $L$ | 单位立体角单位面积功率 | W/sr·m² |

### BRDF 与渲染方程

双向反射分布函数：$f_r(\omega_i \to \omega_r) = dL_r(\omega_r) / dE_i(\omega_i)$

渲染方程：
$$
L_o(p, \omega_o) = L_e(p, \omega_o) + \int_{H^2} f_r(p, \omega_i \to \omega_o) L_i(p, \omega_i) \cos\theta_i \, d\omega_i
$$

### 路径追踪
蒙特卡洛积分 $\int f \approx (1/N)\sum f(X_i)/p(X_i)$ + 俄罗斯轮盘赌（无偏） + 直接光照重要性采样。高级方法：BDPT（双向）、MLT（马尔科夫链）、Photon Mapping（有偏，擅长焦散）。

## 几何处理

- **贝塞尔曲线**：de Casteljau 算法（多次线性插值），凸包性质，分段 C¹ 连续需共线等长
- **Loop 细分**：三角形一分四，新旧顶点分别加权更新
- **Catmull-Clark**：任意多边形 → 四边形，一次细分后奇异点不再增加
- **网格简化**：边坍缩 + 二次误差度量（Quadric Error Metrics）

## 材质模型

- **菲涅尔**：$R(\theta) = R_0 + (1-R_0)(1-\cos\theta)^5$（Schlick 近似）。掠射角反射率高
- **微表面**：粗糙度 = 微表面法线分布 [扩散 ↔ 集中]。当前 PBR 业界标准
- **各向异性**：拉丝金属的条形高光（不同方向反射不同）
- **次表面散射**：BSSRDF 泛化 BRDF（皮肤、玉石、牛奶）
- **参与介质**：光在介质中散射吸收（雾、云、烟）

## 相机与光场

- **曝光三要素**：光圈（F数 = 焦距/直径）、快门速度、ISO
- **薄透镜近似**：$1/f = 1/z_i + 1/z_o$
- **景深**：CoC（Circle of Confusion）不在焦点上的点形成模糊圆
- **光场**：4D 函数 $L(u,v,s,t)$，光场相机拍摄后重聚焦

## 前向 vs 延迟渲染

| | Forward | Deferred |
|:--|:--------|:---------|
| 光照 | 逐对象逐光源 | G-Buffer + Lighting Pass |
| DrawCall | O(对象×光源) | O(光源) |
| MSAA | 支持 | 不支持 |
| 半透明 | 支持 | 不支持（需 Forward 混合） |
| 硬件 | 要求低 | 需 MRT+SM3.0 |

现代趋势：**Forward+**（Tile-based 光分类）和 **Clustered Rendering**（3D 空间划分光簇）。

## 动画物理

- **质点弹簧**：结构/剪切/弯曲弹簧。阻尼力与相对速度有关
- **FK/IK**：正向运动学（关节角→末端）vs 逆运动学（末端→关节角，解不唯一）
- **数值积分**：欧拉 → 中点法 → RK4 → Verlet / Position-Based（常用于游戏物理）

## 引擎架构

GAMES104 五层：Tool Layer → Function Layer → Resource Layer → Core Layer → Platform Layer。

## 颜色科学

人眼三种锥形细胞（S/M/L）。同色异谱：不同光谱产生相同颜色感知。sRGB、CIE XYZ、色域。
