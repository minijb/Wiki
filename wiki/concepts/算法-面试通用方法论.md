# 算法面试通用方法论

系统化整理算法面试中的核心模式：从图论到高级数据结构，从链表双指针到数学几何，再到面试策略——构建完整的解题武器库。

## 图论算法

### 最小生成树

| 算法 | 核心数据结构 | 选点策略 | 复杂度 |
|------|-------------|----------|--------|
| Prim | `minDist` + `isInTree` | 选离**生成树**最近的节点 | $O(V^2)$ 或 $O(E\log V)$（堆优化） |
| Kruskal | 并查集 + 边排序 | 按权重升序，不构成环则加入 | $O(E\log E)$ |

> [!tip] Prim vs Dijkstra
> Prim 选择离**生成树**最近的节点，Dijkstra 选择离**起点**最近的节点。两者结构几乎一致，区别仅在 `minDist` 的更新逻辑。

### 并查集 (DSU)

核心操作：`find`（路径压缩）+ `union`（合并集合）。路径压缩 `father[u] = find(father[u])` 均摊接近 $O(1)$。

### 拓扑排序

DAG 线性排序，判断图中是否有环。反复移除入度为 0 的节点及其出边。若图中还有节点但无入度为 0 的节点 → **一定有环**。

## A\* 路径搜索

评估函数 $F = G + H$（$G$ 为实际步数，$H$ 为启发预估）。四种优化策略：

1. **OpenList 优化**：优先队列替代线性搜索
2. **邻居优化**：随机化方向顺序、JPS 跳点搜索（跳过冗余节点）
3. **启发函数优化**：引入拐弯惩罚 $F = G + H + C$、障碍物通行代价
4. **地图优化**：HPA 分层——先高层规划再低层细化

## 红黑树

### 核心约束

- 叶子节点（NIL）和根节点**一定是黑色**
- 红色节点不能连续（父和子必为黑）
- **所有路径**的黑色节点数量相同

### 插入 4 种情况

| 情况 | 父节点 | 叔节点 | 处理 |
|------|--------|--------|------|
| 1 | 黑 | — | 直接插入红节点 |
| 2 | 红 | 红 | 父、叔、爷颜色反转 |
| 3 | 红 | 黑（直线） | 旋转 + 换色 |
| 4 | 红 | 黑（折线） | 先旋转到直线 → 按情况 3 |

### 删除 5 种情况

单红直接删、单子红替换黑、双子找前驱替换。兄弟黑时按对侄/顺侄/双侄黑分别处理；兄弟红时旋转转为兄弟黑。

## 经典模式

### 链表操作

| 模式 | 典型题目 | 关键技巧 |
|------|----------|----------|
| 双指针迭代 | 反转链表 LC 206 | `pre` + `cur` + `next` |
| 快慢指针 | 删除倒数第 N 个 LC 19 | dummy 节点 + 固定间距 |
| 节点交换 | 两两交换 LC 24 | 维护前驱 + 当前 + 后继 |

### 双指针 / 滑动窗口

| 模式 | 典型题目 | 思想 |
|------|----------|------|
| 左右指针收缩 | 盛最多雨水 LC 11 | 移动较矮一侧 |
| 滑动窗口 + 哈希 | 无重复字符最长子串 LC 3 | 记录字符最后位置 |
| 可变窗口 | 长度最小子数组 LC 209 | 扩张到满足条件再收缩 |

### 数组变换

- **轮转数组**：取模映射到新位置
- **旋转矩阵**：转置 + 左右翻转（两步到位）
- **荷兰国旗**：三指针一次遍历划分 0/1/2

### 哈希妙用

- **两数之和**：互补查找 $O(n)$
- **构造最长回文串**：字符配对计数
- **只出现一次的数字**：异或 $a \oplus a = 0$

### 栈

- **有效括号**：匹配弹出，最终栈空
- **比较版本号**：逐段解析，防溢出用 `long long`

## 游戏开发中的数学几何

| 问题 | 方法 |
|------|------|
| 目标在左侧还是右侧 | `Cross(forward, direction).y` 符号 |
| 点是否在三角形内 | 三边叉积同号（点积互为正） |
| 2D 点绕原点旋转 | $X = x\cos\alpha - y\sin\alpha$, $Y = x\sin\alpha + y\cos\alpha$ |
| 面向还是背向 | `Dot(forward, toTarget)` 符号 |
| 反射向量 | $R = I - 2(I\cdot N)N$ |
| 矩形相交判定 | 中心距离 ≤ 边长和的一半 |
| 相交区域 | `Xc1 = max(Xa1, Xb1)`, `Xc2 = min(Xa2, Xb2)` |

## 面试策略

> [!tip] 面试五步法
> 1. 确认边界条件（输入范围、特殊情况）
> 2. 口述思路后再编码
> 3. 写完后主动跑测试用例
> 4. 分析时间复杂度与空间复杂度
> 5. 讨论可能的优化方向

### 题型优先级

| 优先级 | 类别 | 原因 |
|--------|------|------|
| **高** | 数组 / 字符串 | 基础中的基础 |
| **高** | 双指针 / 滑动窗口 | 高频经典，容易出 bug |
| **高** | 二叉树 / BST | 递归思维综合考察 |
| 中 | 动态规划 | 门槛高但必会经典题 |
| 中 | 回溯 | 模板化后稳定性高 |
| 中 | 栈 / 队列 | 括号匹配、单调栈等 |
| 低 | 图论 | 少数公司考察 |
| 低 | 高级数据结构 | 主要考理解而非手写 |
