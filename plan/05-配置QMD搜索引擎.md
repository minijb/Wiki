# 05 — 配置 QMD 搜索引擎

## 目标

配置 QMD 本地搜索引擎作为 Wiki 的主要检索后端，与 `/query` 和 `/lint` 技能集成。

## 步骤

1. **确认 QMD MCP 可用**：`qmd:qmd` skill 已就绪，MCP 服务器已连接
2. **确认 `.qmd/` 缓存目录**：已在步骤 01 中创建，由 QMD 自动管理
3. **初始索引建立**：在首次 `/ingest` 操作完成后触发 QMD 建立初始索引
4. **增量更新**：后续每次 `/ingest` 操作后自动更新 QMD 索引

## QMD 在技能中的角色

| 技能 | QMD 用法 |
|------|----------|
| `/query` | BM25 + 向量搜索 + LLM 重排序 → 精准检索相关页面 → 综合生成答案 |
| `/lint` | 全局搜索 → 检测孤立页面、断链、矛盾声明、陈旧内容 |

## 关键设计决策

- `.qmd/` 目录由 QMD 自动管理，**不手动编辑**
- index.md 作为辅助导航，QMD 作为主要检索手段
- 两种调用方式：CLI 和 MCP 服务器（当前使用 MCP）

## 验证

1. 调用 `qmd:qmd` skill 确认 MCP 服务器正常响应
2. 在至少一个 Wiki 页面存在后，执行 QMD 搜索验证返回正确结果
3. 确认 `.qmd/` 目录下生成了索引缓存文件
4. 执行 `/ingest` 后确认 QMD 索引自动更新
5. 执行 `/query` 验证 QMD 检索→阅读→综合 全流程
6. 执行 `/lint` 验证 QMD 全局搜索→检测问题 全流程
