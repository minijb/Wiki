# 01 — 创建目录结构

## 目标

在项目根目录下创建符合 Karpathy 三层架构规范的 Wiki 工作区目录骨架。

## 目录清单

```
F:\Project_AI\wiki/
├── raw/                         # 原始来源层（不可变，LLM 只读不写）
│   ├── assets/                  # 本地图片等附件
│   ├── gamedev/
│   │   ├── rendering/           # 渲染、Shader、URP/HDRP
│   │   ├── physics/             # 物理、碰撞检测
│   │   ├── animation/           # 动画、程序化动画
│   │   ├── networking/          # 网络同步、多人游戏
│   │   ├── ai/                  # AI、行为树、NavMesh
│   │   ├── gameplay/            # 玩法系统、战斗、技能
│   │   ├── ui/                  # UGUI、UI Toolkit
│   │   ├── audio/               # 音频系统
│   │   └── optimization/        # 性能优化、内存管理
│   ├── cs/
│   │   ├── languages/           # C#, C++, Lua, Python
│   │   ├── design-patterns/     # GoF, 游戏编程模式
│   │   ├── architecture/        # SOLID, DDD, ECS, 软件架构
│   │   └── algorithms/          # 算法与数据结构
│   └── tools/
│       ├── git/                 # 版本控制
│       ├── ide/                 # Rider, VS, VS Code
│       ├── docker/              # 容器化
│       └── ci-cd/               # 持续集成/部署
├── .claude/skills/              # 技能定义目录
├── drafts/                      # 用户不完善笔记（打磨区，非 Karpathy 原生）
├── wiki/                        # Wiki 层（LLM 拥有）
│   ├── concepts/                # 概念页面
│   ├── entities/                # 实体页面
│   ├── sources/                 # 来源摘要页面
│   └── comparisons/             # 对比分析页面
└── .qmd/                        # QMD 索引缓存（自动管理）
```

## 验证

1. 确认 `raw/` 存在，含 `assets/` + `gamedev/`（9子目录）、`cs/`（4子目录）、`tools/`（4子目录）
2. 确认 `wiki/` 存在，含 `concepts/`、`entities/`、`sources/`、`comparisons/` 四个子目录
3. 确认 `.claude/skills/`、`drafts/`、`.qmd/` 独立目录存在
4. 确认根目录没有 `index.md` 或 `log.md`（这些属于 wiki/ 内部，由后续步骤创建）
