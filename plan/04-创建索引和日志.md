# 04 — 创建 wiki/index.md 和 wiki/log.md

## 目标

在 **`wiki/` 内部**创建双入口导航文件（Karpathy 规范：index 和 log 属于 Wiki 的一部分）：
- `wiki/index.md` — 内容导向目录（Wiki 所有页面的索引）
- `wiki/log.md` — 时间导向日志（操作记录，只追加）

## wiki/index.md 初始骨架

- 顶部说明：Wiki 内容索引，由 LLM 维护。LLM 回答查询前先读此文件定位。
- 按页面类型分节（对应 Karpathy 定义的页面类型 + wiki/ 子目录）：
  - **Concepts（概念页面）** `wiki/concepts/` — 跨来源的概念/主题/方法论
  - **Entities（实体页面）** `wiki/entities/` — 具体事物/人物/项目
  - **Source Summaries（来源摘要）** `wiki/sources/` — 每篇 raw 来源对应一个摘要
  - **Comparisons（对比分析）** `wiki/comparisons/` — 跨来源的矛盾/对比
  - **Overview（综合）** `wiki/overview.md` — 高层整合
- 每项格式：`- [[子目录/页面标题|标题]] — 一行摘要 [可选元数据]`
- 标记为"待首次 Ingest 后填充"

## wiki/log.md 初始骨架

- 顶部说明：操作日志，只追加不修改
- 条目格式（Karpathy grep-friendly）：
  ```
  ## [YYYY-MM-DD] 操作类型 | 摘要
  ```
  可通过 `grep "^## \[" log.md | tail -5` 快速查看最近 5 条
- 初始条目：`## [YYYY-MM-DD] init | Wiki 工作区创建`

## 验证

1. 确认 `wiki/index.md` 存在
2. 确认 `wiki/index.md` 按页面类型分节（Concepts/Entities/Source Summaries/Comparisons/Overview）
3. 确认条目格式符合 `[[wikilink]] — 摘要` 规范
4. 确认 `wiki/log.md` 存在
5. 确认 `wiki/log.md` 包含初始创建记录（`## [日期] init | ...` 格式）
6. 确认 `wiki/log.md` 格式可被 `grep "^## \["` 解析
7. 确认根目录没有 index.md 或 log.md（它们不属于根目录）
