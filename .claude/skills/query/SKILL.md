# /query — Wiki 查询

从 Wiki 知识库中检索信息并综合生成答案。

## 工作流

### 1. 理解问题
- 解析用户查询，识别关键术语和意图
- 判断问题类型：概念解释、关系梳理、操作指南、对比分析

### 2. 导航定位
- 先读取 `wiki/index.md`，按分类（Concepts/Entities/Source Summaries/Comparisons）快速定位候选页面
- 列出可能相关的 `[[wikilink]]` 引用

### 3. QMD 深度检索
- 调用 `qmd:qmd` skill 进行语义搜索
- 搜索策略：
  - 用查询关键词进行 BM25 + 向量搜索
  - 让 QMD 的 LLM 重排序返回最相关结果
- 检索范围覆盖 `wiki/` 和 `raw/`

### 4. 阅读与综合
- 读取 QMD 返回的相关页面（优先前 5 个）
- 跨页面综合信息，识别：
  - 核心答案
  - 相关概念（提供 `[[wikilink]]` 引用）
  - 信息来源出处

### 5. 生成答案
- 根据问题类型选择输出格式：
  - **概念解释** — 定义 + 关键点 + 相关链接
  - **关系梳理** — Mermaid 图表 + 文字说明
  - **操作指南** — 步骤 + 注意事项
  - **对比分析** — 表格 + 总结
- 答案中引用 Wiki 页面用 `[[wikilink]]` 语法

### 6. 可选归档
- 如果查询涉及的知识综合结果有长期价值，提议写入 `wiki/` 作为新页面：
  - 对比分析 → `wiki/comparisons/`
  - 综合概述 → 更新 `wiki/overview.md`
- 用户确认后创建，按 ingest 流程更新 `wiki/index.md` 和 `wiki/log.md`

## 失败处理
- QMD 无结果 → 扩大搜索词或直接用 `wiki/index.md` 手动遍历，若仍无结果则如实告知
- 相关页面信息矛盾 → 标记矛盾点，建议运行 `/lint`，继续综合给出最佳答案
- 来源信息不完整 → 标注信息缺失，不编造

## 输出
- 直接回答用户问题
- 末尾附相关 Wiki 页面链接列表（含 `[[wikilink]]` 路径）
